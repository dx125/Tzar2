Tzar2 {VERSION} - closed beta for Windows 10/11 (64-bit)

Thank you for testing. This build is not public: please do not share it.

STARTING
  Run Tzar2.exe. On the first start Tzar2 looks for your copy of TZAR: The Burden of the Crown (GOG, Steam or CD) and
  imports its art, sound and data; this takes a few minutes and never changes your copy. If it is not found, choose
  the folder that contains Tzar.exe. Tzar2.console.exe is the same game with a console window that shows its messages.

YOUR DATA
  Settings, saved games, replays, logs and the imported game live in
    %APPDATA%\Godot\app_userdata\Tzar2
  Uninstalling (or deleting this folder, for the portable zip) keeps them. Delete that folder to start over.

CRASH REPORTS
  On the first start Tzar2 asks whether it may send crash reports. Nothing is sent unless you agree; you can change it
  in Settings. Reports that are not sent stay in %APPDATA%\Godot\app_userdata\Tzar2\crash-reports\outbox.

REPORTING A BUG
  Write down what you did, what you expected and what happened, then attach:
    * the run's log folder: %APPDATA%\Godot\app_userdata\Tzar2\logs\<date-time of the run>\ (zip the whole folder)
    * the match's replay: %APPDATA%\Godot\app_userdata\Tzar2\replays\ (the newest .t2rep), or crash-replay.t2rep
      from the log folder after a crash
    * version.txt from this folder
  Send it through the beta's feedback channel (the bug form is described in the invitation).
