# M4 trigger, conversation and campaign placeholders, stream B (UNVERIFIED)

Status: **open**. This register lists every runtime rule of the legacy trigger engine, the conversations and the
campaign layer (ADRs 0130–0139) that neither the Editor Manual (Appendix C) nor a measurement fixes. Each rule is
implemented in one place and marked `UNVERIFIED` in the code with its unknown. Resolve them by editor experiments
(build a test map in `TzarEdit.exe`, play it in `Tzar.exe`) or captures (`t2 fidelity`, ADR 0030), then update the
code, this table and the tests. Unknowns of stream A (the converter, UNK-70…UNK-89) are in its own register.
